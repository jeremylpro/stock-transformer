# AGENTS.md - stock-transformer
This project aims to predict the return and direction of a stock over a 1, 5, or 20-day time period using technical indicators and news.
Note that the computer is an Intel Mac, and there are no PyTorch or Tensorflow wheels for it.

## Requirements
- Must implement/fix anything exactly as specification describes, if there is any reason you cannot say so
- Every time you finish an implementation/fix:
  - Must git commit to make sure you can roll back
  - Must create or update the relevant tests and ensure that they all succeed
